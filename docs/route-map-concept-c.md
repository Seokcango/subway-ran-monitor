# 노선도 메인 시안 C · 수송 흐름 지도

> 작성일 2026-11-08 · 시안 캔버스: [노선도 메인 시안](https://claude.ai/artifact/HfY9wTiHqG5gbGQWWpGtES) (보드 C)
> 현재 시안의 노선·역·수치는 모두 **가상 예시 데이터**입니다.

## 1. 개요

시안 C는 노선도 메인을 "어디가 많이 붐비는가"를 한눈에 보여주는 지도로 만듭니다.
핵심 메시지는 헤드라인 그대로 **"선이 굵을수록 많이 탑니다"** 입니다.

- **목표**: 사용자가 노선 구조와 구간별 이용량을 함께 읽고, 붐비는 구간과 노선 추세를 3초 안에 파악
- **대상 화면**: 서비스 메인(첫 화면), 데스크톱 1440px 기준 + 반응형

## 2. 화면 구성

```
┌───────────────────────────────────────────────────────────────────────┐
│ [서비스명] 노선도 · 오늘 누적                     [오늘][이번 주][이번 달] │
│ 선이 굵을수록 많이 탑니다                                               │
├───────────────────────────────────────────────┬───────────────────────┤
│                                               │ 가장 붐빈 구간 TOP 5   │
│                                               │ 중앙→강변 ██████ 5.1만 │
│            흐름 지도 (구간 굵기 = 수송량)        │ ...                   │
│                                               ├───────────────────────┤
│                                               │ 노선별 수송 분담       │
│                                    [굵기 범례] │ [38%|27%|21%|14%]     │
│                                               ├───────────────────────┤
│                                               │ 최근 7일 추이 (2×2)    │
│                                               │ [1호선 ▲4%][2호선 ▼2%] │
│                                               │ [3호선 ▲1%][4호선 ▲6%] │
└───────────────────────────────────────────────┴───────────────────────┘
```

| 영역 | 내용 | 데스크톱 (1440px) | 모바일 |
| --- | --- | --- | --- |
| 헤더 | 서비스명 · 헤드라인 · 기간 토글(오늘/이번 주/이번 달) | 가로 1줄, 하단 2px 구분선 | 토글이 헤드라인 아래로 줄바꿈 |
| 흐름 지도 | 구간 굵기 = 수송량인 노선도, 굵기 범례 | 좌측, 최소 640px, 남는 공간 차지 | 전체 폭, 비율 유지하며 축소 |
| 붐빈 구간 TOP 5 | 구간명 · 가로 막대 · 수송량 | 우측 패널 1번째 (최소 360px) | 지도 아래로 쌓임 |
| 노선별 수송 분담 | 100% 누적 막대 + 범례 | 우측 패널 2번째 | 지도 아래로 쌓임 |
| 최근 7일 추이 | 노선별 스파크라인 카드 4개 (2×2) | 우측 패널 3번째 | 2×2 그리드 유지 |

- 콘텐츠 최대 폭 1440px, 좌우 여백 24px, 상하 여백 32px
- 블록 간격: 지도↔패널 24px, 패널 내부 섹션 간 28px
- 레이아웃: `flex-wrap` 행 — 지도 `flex: 999 1 640px`, 패널 `flex: 1 1 360px`

## 3. 시각화 상세

네 가지 시각화는 같은 노선 색을 공유하고, 각자 하나의 질문에 답합니다.

### 3.1 흐름 지도

**질문**: 어느 구간이 가장 붐비나?

| 요소 | 규칙 |
| --- | --- |
| 선 굵기 | 구간 수송량. 4–20px (1만 명 ≈ 4px, 3만 명 ≈ 12px, 5만+ = 20px) |
| 굵기 스케일 | 제곱근 스케일 권장 — 작은 구간도 끊기지 않고, 큰 구간이 지도를 덮지 않음 |
| 선 색 | 노선 색 (토큰 참고) |
| 선 끝/이음 | `stroke-linecap: round`, `stroke-linejoin: round` |
| 역 마커 | 흰 원 + 검정 2.5px 테두리. 환승역 r 9–10, 일반역 r 5 |
| 역명 | 13px, #3F3F46. 상위 구간 양 끝 역·환승역은 700 굵기, #18181B |
| 범례 | 지도 우하단. 1만 / 3만 / 5만+ 세 단계 선 굵기 샘플 |
| 배경 | 흰 카드(#FFFFFF), 모서리 16px |

굵기 계산 예시:

```js
const MIN_W = 4, MAX_W = 20;
const width = (v, vMax) => MIN_W + (MAX_W - MIN_W) * Math.sqrt(v / vMax);
```

### 3.2 가장 붐빈 구간 TOP 5

**질문**: 정확히 몇 명이며 순위는?

- 가로 막대, 1위 대비 비율 길이 (막대는 0에서 시작)
- 막대 색 = 해당 노선 색, 높이 14px, 오른쪽 끝만 3px 라운드
- 행 구성: `구간명(120px) | 막대(1fr) | 수치(48px, 우측 정렬)`
- 수치는 만 단위 소수 1자리 (예: `5.1만`), Space Grotesk 700
- 방향 표기: `중앙→강변`

### 3.3 노선별 수송 분담

**질문**: 각 노선이 전체의 몇 %를 나르나?

- 100% 누적 막대 1줄, 높이 32px, 조각 사이 2px 간격
- 조각 안에 % 흰 글씨 (조각 폭이 좁으면 막대 밖 라벨로 이동)
- 하단 범례: 노선 색 칩 10px + 노선명
- 정렬: 분담률 높은 순

### 3.4 최근 7일 추이

**질문**: 노선별 이용이 늘고 있나?

- 노선별 스파크라인 카드 4개, 2×2 그리드
- 선 2.5px, 노선 색, 마지막 점(r 3) 강조
- 카드 상단: 노선명 + 전주 대비 증감률
- 증감 표기: `▲ 4%` 녹색(#1D6B3A) / `▼ 2%` 빨간색(#A33A1E) — 기호를 함께 써서 색에만 의존하지 않음
- 축·눈금 없음 (추세만 전달)

## 4. 인터랙션 (구현 시 제안)

시안은 정적 화면이며, 아래 동작은 제안 사항입니다.

| 트리거 | 동작 |
| --- | --- |
| 기간 토글 (오늘/이번 주/이번 달) | 지도 굵기, TOP 5, 분담률을 해당 기간 누적으로 전환. 추이는 7일/4주/6개월로 변경 |
| 지도 구간 탭/호버 | 해당 구간 강조(나머지 흐림), 구간 시간대별 수송량 패널 노출 |
| 역 탭 | 역 상세(승하차 인원, 환승 노선, 다음 열차)로 이동 |
| TOP 5 항목 탭 | 지도에서 해당 구간 강조 (양방향 연동) |
| 노선 범례/분담 막대 탭 | 해당 노선만 지도에 남기는 필터 |

- 터치 대상 최소 44px
- 지도 구간에는 보이지 않는 넓은 히트 영역(투명 stroke 24px 이상)을 둬서 가는 선도 쉽게 누를 수 있게 함
- 기간 토글은 `<button aria-pressed>`로 상태 표시

## 5. 데이터 요구사항

화면 전체는 **구간(역→역) × 일자 수송량** 하나의 테이블로 대부분 계산됩니다.

| 데이터 | 필드 | 단위 / 집계 | 쓰이는 곳 |
| --- | --- | --- | --- |
| 노선 | `line_id`, `name`, `color` | 고정 마스터 | 전체 |
| 역 | `station_id`, `name`, `x`, `y`, `is_transfer` | 고정 마스터 | 흐름 지도 |
| 구간 | `segment_id`, `line_id`, `from_station_id`, `to_station_id`, `direction` | 고정 마스터 | 흐름 지도, TOP 5 |
| 구간 수송량 | `segment_id`, `date`, `hour`, `passengers` | 시간 단위 원천, 일/주/월 합계 | 지도 굵기, TOP 5, 구간 패널 |
| 노선 수송량 | `line_id`, `date`, `passengers` | 일 합계 (구간 합에서 파생 가능) | 분담률, 7일 추이 |

계산식:

- 분담률 = 노선 수송량 ÷ 전체 수송량 합
- 증감률 = (최근 7일 합 ÷ 그 전 7일 합) − 1
- 갱신 주기: 오늘 누적은 최소 10분 단위 권장

API 응답 예시:

```json
{
  "period": "today",
  "asOf": "2026-11-08T18:40:00+09:00",
  "segments": [
    { "segmentId": "L1-03", "lineId": "L1", "from": "중앙", "to": "강변", "passengers": 51000 }
  ],
  "lineShare": [
    { "lineId": "L1", "share": 0.38 }
  ],
  "trend": [
    { "lineId": "L1", "daily": [0, 0, 0, 0, 0, 0, 0], "changeRate": 0.04 }
  ]
}
```

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `bg` | `#FAF9F6` | 페이지 바탕 |

| `text` | `#18181B` | 본문 |
| `text-secondary` | `#5B5B63` | 라벨, 보조 문구 |
| `border` | `#D4D2CC` | 비선택 버튼 |
| `line-1` | `#2F6FDB` | 1호선 |
| `line-2` | `#D9691E` | 2호선 |
| `line-3` | `#13887A` | 3호선 |
| `line-4` | `#7A4FD0` | 4호선 |
| `positive` | `#1D6B3A` | 증가 |
| `negative` | `#A33A1E` | 감소 |

| 타이포 | 값 |
| --- | --- |
| 헤드라인 (H1) | Noto Sans KR 900, 36px, letter-spacing −0.02em |
| 섹션 제목 (H2) | Noto Sans KR 900, 16px |
| 본문 / 라벨 | Noto Sans KR 400–700, 12–14px |
| 숫자 | Space Grotesk 700 |

| 형태 | 값 |
| --- | --- |
| 카드 모서리 | 12–16px |
| 버튼 모서리 | 8px |
| 버튼 높이 | 최소 44px, 테두리 2px |

- 노선 색은 실제 노선 색이 정해져 있다면 그 값으로 교체
- 흰 배경 대비 텍스트 명도 대비 4.5:1 이상 유지
